# Limitations and honest roadmap

## Known limitations in this hackathon build

- The catalogue is small and curated; it is not a complete India-wide index.
- The rules are screening heuristics, not the official decision procedure.
- Source freshness is labelled but not checked live by the API.
- Hindi copy is an interaction proof and needs native-language review.
- No OCR, voice, state-specific workflow, or official application connector is
  included in the core demo.
- “Estimated time saved” is a transparent heuristic, not a measured field trial.

## Next 30 days

1. Add a signed, versioned ingestion pipeline from approved official pages.
2. Add source-diff alerts and human review for changed eligibility text.
3. Expand Hindi and add one additional high-need Bharat language after review.
4. Pilot with a CSC/NGO facilitator and measure hand-off completion.

## Next 90 days

1. Hybrid multilingual retrieval over reviewed source chunks.
2. Consent receipts and redacted audit trail for facilitator workflows.
3. State-specific policy packs with a common schema.
4. Optional OCR/voice input with explicit deletion and no credential storage.
5. Audited connectors that can open official forms but require a human to submit.
