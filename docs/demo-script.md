# 2–3 minute demo script

## 0:00–0:20 — the problem

“A citizen can explain a need but should not have to know which department,
document, or deadline to search for. A fluent answer is not enough: an agent
must show evidence and a safe next action.”

## 0:20–0:45 — profile intake

Click **Small farmer**. Say: “The user enters only broad facts. HaqSetu
explicitly tells them not to enter Aadhaar, OTPs, bank passwords, or document
numbers.”

## 0:45–1:15 — agent workflow

Click **Analyze my options**. Narrate the four trace stages: intake, scheme
discovery, evidence checker, action planner. “This is a deterministic demo path,
so the same input is reproducible and each result can be inspected.”

## 1:15–1:45 — unique feature

Expand a result card. Show the official URL, manual freshness warning, matched
rule, and the screening-only status. Then show **Counterfactual check**: “Instead
of pretending to approve or reject, the agent tells us which fact could change
the signal and why it needs official verification.”

## 1:45–2:10 — Bharat-first UX and control

Toggle **हिं** and **Low data**. Say: “The core interaction works in Hindi and
with reduced visual data.” Tick consent and prepare the local draft checklist:
“This is a reversible local aid; nothing is submitted.”

## 2:10–2:30 — impact and close

Point to schemes reviewed, source count, and estimated time saved. Close:
“HaqSetu is a bridge from a citizen's question to verified official next steps,
with uncertainty and consent visible by design.”
